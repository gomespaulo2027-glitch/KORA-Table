# KORA Table Showcase

Cria um website de demonstração profissional e fictício para um negócio angolano chamado "KORA Table", um restaurante contemporâneo em Luanda. O objetivo deste projeto é servir como nosso primeiro site de teste para aprender o fluxo Lovable → GitHub → Vercel → publicação.

REQUISITOS:
- Mobile-first, excelente em Android e desktop.
- Visual premium, moderno e elegante, mas leve e rápido.
- Idioma: português de Angola/português neutro.
- Marca fictícia: KORA Table.
- Não usar conteúdo, logotipo, fotos ou identidade de uma empresa real.
- Criar identidade visual própria: fundo claro quente, tons terrosos/escuros, tipografia elegante, bastante espaço, cards refinados e microanimações discretas.
- Header com logo textual KORA Table, navegação e CTA "Reservar mesa".
- Hero forte com título: "Sabores de Angola, reinterpretados à mesa." Subtítulo curto e CTA.
- Seção "A nossa cozinha" apresentando proposta gastronómica.
- Menu com categorias e pratos fictícios, preços em Kz.
- Galeria visual usando imagens remotas apropriadas de comida/restaurante ou placeholders elegantes; não copiar imagens de negócios reais.
- Seção de experiência/ambiente.
- Depoimentos claramente fictícios de demonstração.
- Horário, localização em Luanda apresentada como endereço fictício de demonstração, telefone fictício e WhatsApp fictício.
- Mapa/CTA de localização pode ser um bloco visual sem integração real.
- CTA final para reserva pelo WhatsApp.
- Footer completo.
- SEO básico: title, description, headings semânticos, favicon simples se possível.
- Acessibilidade: contraste, alt text, navegação por teclado, botões claros.
- Responsividade e estados hover/focus.
- Não adicionar autenticação, banco de dados, Supabase ou pagamentos nesta primeira versão.
- Não adicionar dependências desnecessárias.
- Não deixar erros TypeScript, ESLint ou build.
- Antes de terminar, faz uma revisão geral do projeto, corrige problemas e garante que todas as rotas/links funcionam.
- O site deve estar pronto para depois conectar ao GitHub e fazer deploy no Vercel.
