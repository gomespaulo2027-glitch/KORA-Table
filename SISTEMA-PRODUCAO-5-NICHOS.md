# Sistema de Produção de Sites — 5 Nichos

## Objetivo

Criar sites profissionais rapidamente a partir de templates reutilizáveis, sem reconstruir cada projeto do zero.

Fluxo padrão:

Cliente → Nicho → Pesquisa → Conteúdo → Template → Adaptação → QA → GitHub → Vercel → Entrega

## Prioridade comercial

1. Restaurantes / cafés
2. Salões / barbearias
3. Clínicas / consultórios
4. Hotéis / alojamentos
5. Empresas de serviços

---

# 1. Restaurantes / cafés

### O problema que vendemos
O negócio depende apenas de Instagram/WhatsApp e perde oportunidades porque o cliente não encontra rapidamente menu, localização, horário, fotos ou forma de reservar.

### Estrutura
- Home
- Menu
- Experiência / Sobre
- Galeria
- Contacto
- WhatsApp
- Reserva
- Localização / mapa
- Horário

### Variáveis
Nome, slogan, cidade, endereço, telefone, WhatsApp, horário, menu, preços, fotos, logo, cores, Instagram, mapa e regras de reserva.

### Template base
KORA Table.

# Processo de 60–90 minutos

## 00–10 min — Pesquisa
- Encontrar negócio
- Ver Instagram/Facebook/Google
- Identificar problema
- Recolher informações públicas
- Não copiar conteúdo protegido sem autorização

## 10–20 min — Conteúdo
Preencher a ficha do cliente:
- Nome
- Slogan
- Serviços/menu
- Contactos
- Localização
- Horários
- Redes
- Fotos
- CTA principal

## 20–55 min — Adaptação
- Duplicar template
- Trocar identidade
- Trocar textos
- Trocar imagens
- Ajustar cores
- Ajustar navegação
- Configurar WhatsApp/contactos
- Rever mobile

## 55–70 min — QA
Testar:
- Menu
- Todas as rotas
- Botões
- WhatsApp
- Telefone
- Imagens
- Formulários
- Links externos
- Responsividade
- Texto
- Ortografia
- SEO básico
- Console/build

## 70–90 min — Publicação
- GitHub
- Build
- Vercel
- URL de produção
- Teste final
- Entrega ao cliente

## Premium — 150.000 Kz+
- Tudo do Profissional
- Estrutura mais personalizada
- Reserva/agendamento conforme necessidade
- Integrações específicas
- Maior volume de conteúdo

Domínio, alojamento ou serviços externos pagos pelo cliente quando aplicável.

---

# Regras comerciais

- Não vender tecnologia; vender resultado.
- Não prometer aumento de vendas garantido.
- Não inventar provas sociais.
- Não publicar dados fictícios como se fossem do cliente.
- Pedir autorização para usar fotos e logotipo.
- Para trabalho personalizado: 50% antes + 50% na entrega.
- Fazer demo com dados fictícios quando o cliente ainda não forneceu material.

# Prospecção

## Onde procurar
- Google Maps
- Instagram
- Facebook
- Diretórios locais
- Pesquisa manual por cidade/nicho

## Priorizar negócios que:
1. Não têm site.
2. Têm site antigo ou difícil de usar no telemóvel.
3. Dependem exclusivamente de Instagram/WhatsApp.
4. Têm boa presença comercial mas pouca informação organizada online.

## Abordagem
Primeiro mostrar o problema e uma solução visual. Só depois falar de preço.

### Roteiro curto

Olá, [NOME]. Vi o trabalho da [EMPRESA] e reparei que os clientes precisam recorrer ao [Instagram/WhatsApp] para encontrar [menu/serviços/preços/localização/agendamento].

Eu trabalho com sites rápidos e adaptados para telemóvel, com essas informações organizadas e botão direto para WhatsApp.

Preparei uma ideia de como isso poderia ficar para a [EMPRESA]. Posso enviar a demonstração?
